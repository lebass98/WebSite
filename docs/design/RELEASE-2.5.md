# EpoBrowser UI 업데이트

macOS 2.5 (빌드 16) · Android 1.2 (버전 코드 3)

## 반영 내용

- 청록 테마, 밝은/어두운 화면 대응, 공통 카드·화면 헤더·상태 안내.
- 탐색과 접을 수 있는 세부 필터, 적용 조건 요약과 초기화.
- macOS 검색 탭별 검색어·유형 복원, 키보드로 선택 가능한 탭.
- 영상·컬렉션 카드의 정보 위계, 추가 로딩 오류 재시도.
- 계정 화면 안내와 Android 로딩·오류 복구, 로그인 진행 중 입력 상태 개선.
- 다운로드 주소 선택·복사 진행 표시와 4K 주소 모음 화면 개선.
- 플레이어 연결 안내, 사이트 플레이어 전환, macOS 재연결 옵션, Android 재생 페이지 오류 복구.
- 자막 만들기 실패 후 재시도와 시스템의 동작 줄이기 설정 지원.
- Android 작은 화면 도구 정리, 필터·작업 시트 스크롤, 기록 전체 삭제 확인.

## 설치 파일

macOS는 `dist/EpoBrowser-2.5.pkg`, Android는 `dist/EpoBrowser-1.2.apk`를 사용한다. macOS 설치 없이 확인할 앱은 `dist/EpoBrowser-2.5-macOS.zip`에도 포함되어 있다.

macOS는 Apple silicon / macOS 26 이상을 대상으로 빌드했다. 기존 배포 파일은 보존했다. 실제 재생 및 계정 동작과 기기별 화면 검증은 빌드 검사와 별도로 확인해야 한다.
