# EpoBrowser UI/UX 개선안

## 목표와 시안

탐색 → 조건 좁히기 → 영상 선택 → 재생 → 다시 찾기의 흐름을 단순하게 만든다. `preview.html`은 추상 썸네일을 사용하는 로컬 시안이다. 검색, 테마, 메뉴, 화질 선택, 카드 밀도를 조작할 수 있다. 예시 데이터만 사용하며 앱 기능과 연결하지 않는다.

## 디자인 방향

차분한 미디어 라이브러리. 강조색은 청록(#087F74), 선택 상태는 옅은 청록 배경과 텍스트 굵기로 구분한다. 시스템 배경과 글자색을 사용해 macOS 라이트·다크 설정을 따른다. Android 다크 모드에서는 밝은 청록을 사용한다. 카드 모서리 12pt, 내부 여백 10pt, 제목·통계·업로더/날짜를 세 단계로 구분한다. 장식 애니메이션보다 즉시 반응하는 탐색을 우선한다.

## 사용자 흐름

1. 탐색 메뉴에서 콘텐츠 유형이나 컬렉션을 선택한다.
2. 검색하거나 목록 위 정렬·카테고리를 사용한다.
3. 세부 필터에서 조건을 고른다. macOS는 화질을 즉시 적용하고 길이·다중 카테고리는 적용 버튼으로 확정한다. Android는 필터 적용 버튼으로 확정한다.
4. 카드를 선택해 기존 재생 창에서 시청한다. 업로더 버튼은 해당 업로드 목록으로 이동한다.
5. 최근 본 영상에서 다시 연다. 삭제 작업은 플랫폼별 확인 흐름을 유지·검토한다.

## 검증 기준

- macOS: 최소 창 크기 1000×600, 밝은/어두운 화면, 긴 제목·업로더, 탭 선택·닫기, 검색과 필터 적용/초기화, 0개·오류·페이지 추가 로딩.
- 접근성: 탭 버튼 키보드 선택, 범위 슬라이더 VoiceOver 조절, 선택 상태, 읽기 순서.
- Android: 360dp 휴대폰, 600dp 중간 화면, 840dp 이상, 필터 시트 스크롤, 큰 글자에서 줄바꿈, 시스템 하단 영역.
- 실제 계정 로그인·네트워크 응답·재생·다운로드·백업은 별도 실기기 확인이 필요하다. 시안의 동작만으로 검증되었다고 보지 않는다.

## 적용 및 빌드

공통 디자인, 탐색, 검색 탭 복원, 컬렉션, 계정, 다운로드, 자막 상태, 플레이어 복구 흐름에 적용했다. 연결된 사이트에서 제공하는 계정 본문은 사이트 화면으로 유지하며 주변 안내와 로딩·오류 처리를 개선했다. 데이터 저장 형식은 유지한다.

macOS 2.5(빌드 16), Android 1.2(버전 코드 3)로 빌드한다. 실제 로그인, 스트리밍, VoiceOver·TalkBack, 큰 글자와 화면 크기별 시각 검증은 별도 실기기 확인 항목이다. 빌드 통과와 실기기 검증은 구분한다.
